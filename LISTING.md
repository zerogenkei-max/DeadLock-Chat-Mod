# Deadlock Chat Mod

By **Genkei**

Change how Deadlock's chat looks, what shows up in it and how long it stays on screen.

## What you can do

- Pick a style: **Default**, **Overwatch 2 style**, **Marvel Rivals style**, **League of Legends style** or Deadlock's own look
- Choose how long chat stays after you click away (0 to 120 seconds), or keep it up all the time
- Pick what shows up: player messages, pings, character callouts, "I'm with you", objectives and system lines
- Show character names, player names or both (character names by default)
- Change the font, text size, colours, opacity, width and position, then share your setup with a theme code

## Install

Close Deadlock, install it with Deadlock Mod Manager and hit **Launch Modded**. In game go to **Settings** and click **CHAT MOD** at the bottom.

Want your settings saved between games, or your own background image? Shoot me a message on discord (**genkei_**) for the Windows customiser (.exe)

Ping history clears between matches and your normal keybinds, channels and mutes still work. It only shows stuff the game already shows you.

Other mods that replace the chat, the Settings menu or the bottom menu bar might clash with this one.
