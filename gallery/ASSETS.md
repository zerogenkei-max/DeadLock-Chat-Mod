# Gallery images

Every gallery image is a real Deadlock capture taken with Steam's F12 key on my
own PC. Valve owns the game artwork in them. No AI-generated images are used.
The gallery was first put together for 0.2.1.

## Cover

`cover-chat.png` is a capture cropped around the chat and Ivy, with a title set
in Inter SemiBold added in PhotoCraft. It is also the Mod Manager thumbnail.

## Settings image

`settings-shortcut-arrow.png` was retaken on 14 November 2026 for 0.2.4. It is
a capture of the Settings screen with the top strip cropped off and a plain
white arrow pointing at the CHAT MOD button.

## Control captures (0.2.4)

`timing-controls.jpg`, `message-controls.jpg` and `name-controls.jpg` were
retaken on 14 November 2026 in the 0.2.4 menu. They are cropped to the Chat Mod
window, with no other edits.

## Style captures

`switchboard.jpg`, `overwatch.jpg`, `rivals.jpg`, `league.jpg`, `native.jpg`
and `hidden.jpg` are straight captures from the 0.2 tests with no edits. The
chat styles they show haven't changed.

## AI help

OpenAI Codex / ChatGPT and Anthropic Claude helped with the code, as stated in
`LISTING.md` and `THIRD_PARTY.md`. None of these images were generated. The
0.2.4 crops and arrow were done with a short Pillow script that only crops and
draws a straight line, run by Claude.
`asset-lock.json` records the checksums of the set. Any new or changed image
needs its source noted here.
